# Data App Studio Source (`src`)

## Overview
Core TypeScript/React source package for the Looker Data App Studio extension and Python Tile runtime. Orchestrates extension authentication, Looker RBAC capability resolution, metadata/artifact persistence, Antigravity Interactions API turn execution, Monty WASM Code Mode & `lkr-dev-cli` sandbox bridging, Conversational Analytics routing, 3-Pillar Health Check auditing, LookML engineering workflows, and UI composition.

## Interface
### Child Subsystems
- [Studio UI Components (`./components/EGM.md`)](./components/EGM.md) — Top-level `App` shell, workspace panes, header/config views, design system primitives, and `PythonTile` mount.
- [Looker Extension Context (`./contexts/EGM.md`)](./contexts/EGM.md) — React context providers (`LookerExtensionProvider`, `MockLookerExtensionProvider`) and `useLookerExtension` hook.
- [Vendored Code Mode Runtime (`./vendor/EGM.md`)](./vendor/EGM.md) — Self-contained `codemode.js` Monty Python WASM sandbox and `@looker/chatty` host bridge.
- `src/styles/` & `src/__tests__/` — Studio CSS theme/layout stylesheet (`index.css`) and Jest unit/visual snapshot suites (`permissions.test.ts`, `miniApps.visual.test.js`).

## Invariants
- `[useStudioController.ts:useStudioController]` Composes `useStudioAuthAndPrefs` -> `useStudioMetadata` -> `useStudioLoaders` -> `useStudioTurn` in strict dependency order.
- `[lookerPermissions.ts:resolveUserCapabilities]` Evaluates `PermissionSet x ModelSet` per role before merging so model sets never bleed across roles, implies `access_data` when explore/develop/LookML/SQL/dashboard/look permissions exist, requires both `explore` and `access_data` for `explorableModels` (adding all models directly when `exploreSet?.has('*')`), and falls back to `m?.can?.show !== false` when `!rolesLoaded`.
- `[lookerPermissions.ts:getAllowedUseCases]` & `[lookerPermissions.ts:extractResolvedUseCase]` `getAllowedUseCases(capabilities, disabledModes)` filters out disabled/unauthorized modes (and `'lookml'` when `readOnly`), falling back to `['app']` when empty; `extractResolvedUseCase(text, promptFallback, allowedModes)` restricts matching to `allowedModes` (defaulting to all resolved modes) and falls back to `'app'` if allowed else `Array.from(allowedSet)[0] || 'app'`.
- `[lookerApi.ts:createDeduplicatedLookerSdkProxy]` & `[lookerApi.ts:coalesceLookerMetadataRequest]` Coalesce concurrent in-flight requests and TTL-cached responses (`15_000 ms`) for `SWR_DEDUPED_METHODS` and metadata GET routes while preserving `__rawSdk` for `ArtifactService` WeakMap keying.
- `[lookerArtifacts.ts:ArtifactService.put]` Tracks `versionByKey` and `knownMissingKeys` in memory to avoid redundant GETs, retrying once after version re-fetch on PUT conflicts; `resolveConversationRelatedContent` never marks `source === 'mention'` or `createdInConversation === false` items for deletion.
- `[antigravityAuth.ts:callInteractionsApi]` & `[antigravityAuth.ts:refreshOAuthSessionIfNeeded]` Defers silent OAuth refresh while `document.visibilityState === 'hidden'`, coordinates multi-tab refreshes via `STUDIO_OAUTH_REFRESH_LOCK_KEY`, and retries HTTP 401 at most once after token refresh.
- `[antigravity.ts:runAntigravityTurn]` & `[antigravity.ts:hydrateInteractionActivitySteps]` `runAntigravityTurn` bounds both `actionRound` and `bridgeRound` to `< 8` iterations, passes `function_result.result` as a plain JS `Struct` object (wrapping JSON arrays/primitives/raw strings into `{ result: ... }`, never `JSON.stringify`), streams live `turnSdk` `METHOD /path (Nms)` lines into `onStatus` and active `codemode` step content, and always decrements `activeInteractionsByEnv` in `finally`; `hydrateInteractionActivitySteps` walks `previous_interaction_id` back to `stopAtInteractionId` (max 12 hops, skipping `[PREWARM:` turns) without persisting `activitySteps` to `user_conversations:${me.id}`.
- `[lkrCliBridge.ts:computeLkrExtensionCacheKey]` Produces deterministic sorted-key SHA-256 cache keys matching `LKR_CLI_SITECUSTOMIZE_PY._compute_cache_key`; `[lkrCliBridge.ts:classifyLookerOperation]` & `[lkrCliBridge.ts:executeLkrExtensionToolRequest]` gate mutating Looker API/SDK calls behind `onPermissionRequest` / `approvedOperations` unless `requirePermission === false`.
- `[studioControllerAuth.ts:useStudioAuthAndPrefs]` Internal `syncSharedEnvironmentId` / `setAgentSession` keep one normalized remote `environmentId` synchronized across all five `StudioMode` sessions (`app`, `dashboard`, `lookml`, `health`, `tile`) once `next.lastInteractionId` is present (initializing untouched sessions with distinct `env_<mode>_isolated` placeholders).
- `[studioControllerTurn.ts:handleSendPrompt]` & `[studioControllerTurn.ts:handleInterjectPrompt]` Guards against unauthenticated/empty sends, prevents an aborted turn's `finally` block from clearing state or dequeuing after an interjection, and processes `lookmlBundle` (canonical `lookml:<projectId>` tab + auto-extracted `*.dashboard.lookml` `lookml_dashboard` tabs), `nativeBundle`, and `bundle` non-exclusively.
- `[dataAppPublisher.ts:upsertPublishedDataApp]` & `[dataAppPublisher.ts:mergeStudioMetadata]` Deduplicate Looker queries via `canonicalQueryJson` and bound persisted chat history to the most recent 500 user/assistant turns.
- `[antigravityPrompts.ts:LOOKER_PROJECT_ONBOARDING_SKILL_MD]`, `[antigravityPrompts.ts:DATA_APP_GUIDE_MD]`, `[antigravityPrompts.ts:BUNDLE_APP_PY]`, `[antigravityPrompts.ts:DASHBOARD_CODEMODE_PREAMBLE_PY]` & `[antigravity.ts:runAntigravityTurn]` `LOOKER_PROJECT_ONBOARDING_SKILL_MD` stays byte-identical to `skills/looker-project-onboarding/SKILL.md` (with trailing `\n`), `DATA_APP_GUIDE_MD`, `BUNDLE_APP_PY`, and `DASHBOARD_CODEMODE_PREAMBLE_PY` terminate with `` `\n `` without `;`, `const step3Directive = \`...\`` stays on a single physical line, and `BUNDLE_APP_PY` uses zero backslash escapes and zero `${` literals while enforcing `invalid-lookml-day-timeframe` and `unbalanced-kpi-grid` static safety gates.

## Side Effects
- `[index.tsx:DOMContentLoaded_listener]` Appends a mount `<div>` to `document.body` and renders `<App />`; `[useStudioController.ts:useStudioController]` assigns `window.__DAB_STUDIO__` inside a post-render `useEffect`.
- `[lookerApi.ts:*]` & `[lookerArtifacts.ts:*]` & `[dataAppPublisher.ts:*]` Execute authenticated Looker 4.0 REST/SDK reads and mutations (`/artifacts`, `/dashboards`, `/dashboard_elements`, `/dashboard_layouts`, `/data_app_extension`, `/inline_extension`, `/queries`, `/folders`, `/user_attributes`, `/session`, `/conversations`), mutate module-level caches (`inFlightMetadataRequests`, `recentMetadataCache`, `servicesBySdk`), and update SWR caches (`SWRConfig.default.cache`, `mutate`).
- `[antigravityAuth.ts:*]` & `[antigravity.ts:*]` & `[conversationalAnalytics.ts:*]` Issue HTTP/SSE calls to `generativelanguage.googleapis.com/v1beta/`, trigger Looker Extension OAuth popups (`extensionSDK.oauth2Authenticate`), read/write `window.localStorage` and `extensionSDK` storage, and mutate `inFlightEnvProvisionByUser`, `sharedEnvExploreSchemas`, and `activeInteractionsByEnv`.
- `[lkrCliBridge.ts:ensureCodeModeLoaded]` & `[healthCheck.ts:runThreePillarHealthCheckViaCodeMode]` Load `./vendor/codemode.js` (Node) or inject `<script src="https://cdn.lkr.dev/cli/codemode/0.0.66/codemode.js">` into `document.head` (browser) and execute Python code in the Monty WASM sandbox.
- `[studioControllerAuth.ts:*]` & `[studioControllerMetadata.ts:*]` & `[studioControllerLoaders.ts:*]` & `[studioControllerTurn.ts:*]` Mutate `document.documentElement` theme attributes, extension host title (`extensionSDK.updateTitle`), router history (`history.push`/`history.replace`), and attach `window`/`document`/`matchMedia` event listeners and `setTimeout` timers.
