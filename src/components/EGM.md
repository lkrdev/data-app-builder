# Studio UI Components (`src/components`)

## Overview
Contains all React UI components for the Looker Data App Studio shell, configuration setup, conversational workspace, Looker embed preview, design system primitives, and the standalone Looker dashboard Python tile mount.

## Interface
- `[App.tsx:App]`, `[App.tsx:ChatMessage]`, `[App.tsx:parseStudioRoute]`, `[App.tsx:STUDIO_MODES]`, `[App.tsx:StudioMode]` — Top-level application shell, `SWRConfig`, router/extension provider selection, and route/type re-exports.
- `[PythonTile.tsx:PythonTile]`, `[PythonTile.tsx:PYTHON_TILE_SKILL_GUIDE]`, `[PythonTile.tsx:DEFAULT_PYTHON_SCRIPT]` — Dashboard tile extension component for binding and executing saved Monty Python scripts against `vars.dashboard_filters`, plus re-exports (`ScriptOutputRenderer`, `renderMarkdownOrHtmlString`, `ScriptStudioView`).
- `[ScriptStudioView.tsx:TilePreviewPane]`, `[ScriptStudioView.tsx:ScriptStudioView]`, `[ScriptStudioView.tsx:ScriptOutputRenderer]`, `[ScriptStudioView.tsx:renderMarkdownOrHtmlString]` — Studio Python script editor/runner pane and tabular/Markdown/HTML/JSON output renderer.
- `[StudioDesignSystem.tsx:StudioButton]`, `[StudioDesignSystem.tsx:StudioBadge]`, `[StudioDesignSystem.tsx:StudioModal]`, `[StudioDesignSystem.tsx:StudioToolbar]`, `[StudioDesignSystem.tsx:StudioCard]`, `[StudioDesignSystem.tsx:StudioSkeleton]`, `[StudioDesignSystem.tsx:StudioDocPreview]`, `[StudioDesignSystem.tsx:StudioButtonVariant]`, `[StudioDesignSystem.tsx:StudioBadgeTone]` — Core design system UI primitives plus `StudioSelect` / `ThemeModeIcon` re-exports.
- `[StudioSelect.tsx:StudioSelect]`, `[StudioSelect.tsx:StudioSelectOption]`, `[StudioSelect.tsx:StudioSelectProps]`, `[StudioSelect.tsx:ThemeModeIcon]` — Custom accessible dropdown wrapping a synchronized hidden native `<select>` element.
- `[StudioHeader.tsx:StudioTopbar]`, `[StudioHeader.tsx:ConfigSetupView]`, `[StudioHeader.tsx:RipperSurfLoader]`, `[StudioHeader.tsx:StudioBrandAgentName]`, `[StudioHeader.tsx:FullScreenToggleButton]`, `[StudioHeader.tsx:ThemeModeSelect]` — Top navigation bar, folder tree picker, auth/mode `/config` setup screen, loading splash, and re-exports from `./StudioDesignSystem`.
- `[StudioWorkspace.tsx:StudioLeftPane]`, `[StudioWorkspace.tsx:StudioRightPane]`, `[StudioWorkspace.tsx:StudioConversationsSidebar]`, `[StudioWorkspace.tsx:StudioComposer]`, `[StudioWorkspace.tsx:StudioCenteredEmptyStage]`, `[StudioWorkspace.tsx:SandboxMarkdownPreviewModal]`, `[StudioWorkspace.tsx:UseCaseInfoTrigger]`, `[StudioWorkspace.tsx:UseCaseInfoModal]`, `[StudioWorkspace.tsx:StarterPromptButtons]` — Split-pane studio workspace, chat thread, `@`-mention / `/`-skill composer, starter prompts, and artifact/embed preview tabs.
- `[StudioWorkspace.tsx:StudioMarkdown]`, `[StudioWorkspace.tsx:normalizeLookerProjectRootUrl]`, `[StudioWorkspace.tsx:parseInViewerLookerLink]`, `[StudioWorkspace.tsx:createLookerEmbedPreloadController]`, `[StudioWorkspace.tsx:resolveLookerEmbedTarget]`, `[StudioWorkspace.tsx:normalizeLookerEmbedUrl]`, `[StudioWorkspace.tsx:isAllowedExternalWindowUrl]`, `[StudioWorkspace.tsx:openOrCopyMarkdownLink]`, `[StudioWorkspace.tsx:copyLinkWithExtensionSdk]`, `[StudioWorkspace.tsx:fetchAvailableLookerConnectionsMarkdown]`, `[StudioWorkspace.tsx:isSandboxMarkdownPath]`, `[StudioWorkspace.tsx:DOC_UI_COMPONENTS]`, `[StudioWorkspace.tsx:USE_CASE_BADGES]`, `[StudioWorkspace.tsx:USE_CASE_GUIDES]`, `[StudioWorkspace.tsx:USE_CASE_GUIDE_ORDER]`, `[StudioWorkspace.tsx:renderUseCaseGuideMarkdown]`, `[StudioWorkspace.tsx:STARTER_PROMPTS_BY_USE_CASE]`, `[StudioWorkspace.tsx:getStarterPromptsForUseCase]`, `[StudioWorkspace.tsx:ALLOWED_EXTERNAL_WINDOW_PATTERNS]`, `[StudioWorkspace.tsx:LookerEmbedTarget]`, `[StudioWorkspace.tsx:LookerEmbedSessionTelemetry]` — Markdown rendering (including inline `$...$` LaTeX operator normalization outside code spans and in-viewer Looker content link routing), Looker Embed SDK preloading controller, non-interactive use-case guide renderers, and `buildDynamicStarterPrompts` / `stripStarterPromptEmojis` / `StarterPromptItem` re-exports.

## Invariants
- `[App.tsx:App]` Wraps the tree in `SWRConfig` (`revalidateOnFocus: false`, `dedupingInterval: 15000`), choosing `MemoryRouter` + `MockLookerExtensionProvider` when `window.__MOCK_LOOKER_EXTENSION__` is defined and `ExtensionProvider` + `LookerExtensionProvider` otherwise.
- `[App.tsx:StudioMain]` Routes in priority order: `PythonTileMount` when `ctl.isTileMount`, `RipperSurfLoader` when `ctl.appInitializing`, `ConfigSetupView` when `ctl.location.pathname === '/config'`, otherwise the `.dab-shell` workspace with `data-theme` and `data-theme-mode`.
- `[PythonTile.tsx:PythonTile]` Guards against concurrent runs with `runningRef.current`, auto-runs bound scripts only when `!isEditing && bindingLoaded && binding?.code` and either `dashboardFilters` JSON changed or `dashboardRunState` transitioned into `'RUNNING'`, and signals `extensionSDK?.rendered?.()` only after view-mode output resolves or when ready without running.
- `[ScriptStudioView.tsx:renderMarkdownOrHtmlString]` Passes full HTML-wrapped strings verbatim and converts all other strings via `renderTddMarkdownToHtml`; `[ScriptStudioView.tsx:ScriptOutputRenderer]` parses JSON arrays of objects into tables (or `'0 rows returned.'`), strings via Markdown/HTML, and other JSON via `<pre>`.
- `[StudioDesignSystem.tsx:StudioModal]` Returns `null` when `!open` and enforces `role="dialog"` + `aria-modal="true"`; `[StudioDesignSystem.tsx:StudioDocPreview]` enforces `pointerEvents: 'none'`, `userSelect: 'none'`, `aria-hidden="true"`, and `tabIndex={-1}`.
- `[StudioSelect.tsx:StudioSelect]` Syncs a hidden native `<select className="dab-studio-select-native">` with the active option and suppresses interaction/Arrow cycling when disabled.
- `[StudioHeader.tsx:StudioBrandAgentName]` Caps agent name input at `maxLength={40}` and resets `draft` on `Escape`; `[StudioHeader.tsx:ConfigSetupView]` disables saving when `busyStatus` is set, `capabilities?.canConfigureExtension === false`, or `authMode === 'apikey' && capabilities?.canManageUserAttributes === false`, and prevents disabling the last enabled mode.
- `[StudioHeader.tsx:StudioTopbar]` Guards folder tree rendering and breadcrumb ancestors with `visited` `Set<string>` cycle checks and disables `'all'`/`'bq'` health-check scopes when `capabilities?.rolesLoaded && capabilities.sqlRunnerConnections.size === 0`.
- `[StudioWorkspace.tsx:isAllowedExternalWindowUrl]` Permits only `http:`/`https:` URLs on `looker.com`, `looker.app`, `google.com`, `cloud.google.com`, `docs.cloud.google.com`, or `github.com` (and subdomains); `[StudioWorkspace.tsx:isSandboxMarkdownPath]` rejects external schemes and requires a `.md` filename before any `?`/`#`.
- `[StudioWorkspace.tsx:resolveLookerEmbedTarget]` Always returns `{ kind: 'preload', target: '/preload', previewMode: 'preload' }` when `isEmptyConversation`, `isHealthCheckMode`, `isLookmlMode`, or `isTileMode` is true, and otherwise resolves `activeContentItem` > `caConversation` (when `caConversation.embedPath` is non-empty) > `preload` if `builderMode === 'dashboard'` > `publishedApp` > `preload`.
- `[StudioWorkspace.tsx:createLookerEmbedPreloadController]` Serializes `syncTarget` calls via sequential `queue` chaining, skips redundant updates when `kind`, `target`, and `nonce` match `lastTarget`, and triggers `asDashboardConnection().run()` on `nonce`-only dashboard updates.
- `[StudioWorkspace.tsx:StudioComposer]` `@`-mention detection suppresses `/`-skill detection (`detectedSlashSkill.open` is forced `false`), excludes hidden explores (`explore.hidden`), deduplicates mentions/chips by `${type}:${id}`, disables `studio-send-btn` when `!isAuthenticated` or prompt+images are empty, and routes busy sends to `handleInterjectPrompt` or `handleQueuePrompt`.
- `[StudioWorkspace.tsx:StudioRightPane]` Hides the right pane when `(isEmptyConversation && !activeViewerDocument) || (!hasViewerContent && !busyStatus && !hadViewerContentRef.current)`, requires `activeMode === 'tile' && Boolean(loadedScript || explicitUseCase === 'tile')` for `isTileMode`, renders hover/focus-bridged `content-tab-popover-<key>` siblings outside `<div role="tab">`, unifies empty viewer states into `"Ready when you are"` / `right-pane-thinking-state`, suppresses the `app.js` code drawer when `builderMode === 'dashboard'`, and hides `ca-embed-preview` when `activePaneKind === 'script' || rightPaneCollapsed || Boolean(activeViewerDocument)`.

## Side Effects
- `[App.tsx:App]` Imports `../styles/index.css` at module load and reads `window.__MOCK_LOOKER_EXTENSION__`.
- `[StudioSelect.tsx:__dabSelectPatched]` Patches `window.HTMLSelectElement.prototype.value` descriptor at module load and defines own `value`/`options` properties on the container DOM node.
- `[PythonTile.tsx:PythonTile]` Calls `extensionSDK?.updateTitle?.('')` and `extensionSDK?.rendered?.()`, fetches tile bindings and scripts via `useSWR`, executes Python via `LkrCodeMode.runPythonCode`, and persists bindings via `bindTileScriptArtifact`.
- `[StudioDesignSystem.tsx:StudioModal]`, `[StudioSelect.tsx:StudioSelect]`, `[StudioHeader.tsx:StudioTopbar]`, and `[StudioWorkspace.tsx:StudioComposer]` attach/remove `document` `keydown`/`mousedown` listeners.
- `[StudioHeader.tsx:FullScreenToggleButton]` Calls `extensionSDK.updateLocation(..., undefined, '_top')` for standalone/spartan fullscreen toggling; `[StudioHeader.tsx:ConfigSetupView]` writes OAuth redirect URIs to `navigator.clipboard?.writeText`.
- `[StudioWorkspace.tsx:StudioComposer]` Runs a 250ms debounced `searchGlobalContentV2` query and mutates `mentionMenuRef.current.scrollTop` when `mockExt.initialExploreScrollTop` is numeric.
- `[StudioWorkspace.tsx:SandboxMarkdownPreviewModal]` & `[StudioWorkspace.tsx:StudioRightPane]` Write `window.__LAST_DOWNLOADED_SANDBOX_MD__`, create/revoke `Blob` URLs to download `.md` files, copy to clipboard, and open Looker paths via `extensionSDK.openBrowserWindow`.
- `[StudioWorkspace.tsx:createLookerEmbedPreloadController]` Initializes `globalThis.window` with a minimal stub when `typeof window === 'undefined'`, initializes Looker Embed SDK, appends/mutates an `<iframe>` in `opts.container`, writes `window.__LOOKER_EMBED_STATE__`, and sends `postMessage` (`looker:ca:layout`) for Conversational Analytics embeds.
- `[StudioWorkspace.tsx:StudioLeftPane]` & `[StudioWorkspace.tsx:StudioRightPane]` Write `window.__LAST_COPIED_THINKING_TRACE__` and copy thinking traces / TDD Markdown / `app.js` source via `navigator.clipboard?.writeText`, attach/remove `window` `mousemove`/`mouseup` listeners during split-pane resizing, and query `GET /connections` / `GET /lookml_models` when inspecting `/admin/connections`.
