# Studio UI Components (`src/components`)

## Overview
Contains all React UI components for the Looker Data App Studio shell, configuration setup, conversational workspace, Looker embed preview, design system primitives, and the standalone Looker dashboard Python tile mount.

## Interface
- `[App.tsx:App]`, `[App.tsx:ChatMessage]`, `[App.tsx:parseStudioRoute]`, `[App.tsx:STUDIO_MODES]`, `[App.tsx:StudioMode]` — Top-level application shell, `SWRConfig`, router/extension provider selection, and route/type re-exports.
- `[PythonTile.tsx:PythonTile]`, `[PythonTile.tsx:PYTHON_TILE_SKILL_GUIDE]`, `[PythonTile.tsx:DEFAULT_PYTHON_SCRIPT]` — Dashboard tile extension component for binding and executing saved Monty Python scripts against `vars.dashboard_filters`, plus re-exports (`ScriptOutputRenderer`, `renderMarkdownOrHtmlString`, `ScriptStudioView`).
- `[ScriptStudioView.tsx:TilePreviewPane]`, `[ScriptStudioView.tsx:ScriptStudioView]`, `[ScriptStudioView.tsx:ScriptOutputRenderer]`, `[ScriptStudioView.tsx:renderMarkdownOrHtmlString]` — Studio Python script editor/runner pane and tabular/Markdown/HTML/JSON output renderer.
- `[StudioDesignSystem.tsx:StudioButton]`, `[StudioDesignSystem.tsx:StudioBadge]`, `[StudioDesignSystem.tsx:StudioModal]`, `[StudioDesignSystem.tsx:StudioToolbar]`, `[StudioDesignSystem.tsx:StudioCard]`, `[StudioDesignSystem.tsx:StudioSkeleton]`, `[StudioDesignSystem.tsx:StudioDocPreview]`, `[StudioDesignSystem.tsx:StudioButtonVariant]`, `[StudioDesignSystem.tsx:StudioBadgeTone]` — Core design system UI primitives plus `StudioSelect` / `ThemeModeIcon` re-exports.
- `[StudioSelect.tsx:StudioSelect]`, `[StudioSelect.tsx:StudioSelectOption]`, `[StudioSelect.tsx:StudioSelectProps]`, `[StudioSelect.tsx:ThemeModeIcon]` — Custom accessible dropdown wrapping a synchronized hidden native `<select>` element.
- `[StudioHeader.tsx:StudioTopbar]`, `[StudioHeader.tsx:ConfigSetupView]`, `[StudioHeader.tsx:RipperSurfLoader]`, `[StudioHeader.tsx:StudioBrandAgentName]`, `[StudioHeader.tsx:FullScreenToggleButton]`, `[StudioHeader.tsx:ThemeModeSelect]` — Top navigation bar, folder tree picker, auth/mode `/config` setup screen, loading splash, and re-exports from `./StudioDesignSystem`.
- `[StudioWorkspace.tsx:StudioLeftPane]`, `[StudioWorkspace.tsx:StudioRightPane]`, `[StudioWorkspace.tsx:StudioOverviewSidebar]`, `[StudioWorkspace.tsx:deriveConversationOverviewData]`, `[StudioWorkspace.tsx:DerivedOverviewData]`, `[StudioWorkspace.tsx:OverviewStageSelection]`, `[StudioWorkspace.tsx:StudioConversationsSidebar]`, `[StudioWorkspace.tsx:StudioComposer]`, `[StudioWorkspace.tsx:StudioCenteredEmptyStage]`, `[StudioWorkspace.tsx:SandboxMarkdownPreviewModal]`, `[StudioWorkspace.tsx:UseCaseInfoTrigger]`, `[StudioWorkspace.tsx:UseCaseInfoModal]`, `[StudioWorkspace.tsx:StarterPromptButtons]`, `[StudioWorkspace.tsx:openContentLinkTargetInViewer]`, `[StudioWorkspace.tsx:renderContentTabIcon]`, `[StudioWorkspace.tsx:formatContentTypeLabel]`, `[StudioWorkspace.tsx:LkrCodeModeApiCallLike]`, `[StudioWorkspace.tsx:OverviewReviewSummary]`, `[StudioWorkspace.tsx:OverviewContentRow]`, `[StudioWorkspace.tsx:OverviewFileRow]`, `[StudioWorkspace.tsx:OverviewSkillRow]`, `[StudioWorkspace.tsx:OverviewApiCallRow]`, `[StudioWorkspace.tsx:OverviewLinkRow]`, `[StudioWorkspace.tsx:DeriveOverviewInput]` — Split-pane studio workspace, chat thread, `@`-mention / `/`-skill composer, starter prompts, Overview sidebar (`296px` full Overview mode or `236px` `.dab-ov-docked` Unified Stage explorer rail / `<= 1080px` slide-over with `Customize Sections` menu, compact `parseLookmlFileDisplay` `E`/`V`/`T`/`D`/`M`/`R`/`F` badge + stem `Changed Files` rows, and collapsible Looker telemetry sections), and artifact/embed preview tabs.

## Invariants
- `[App.tsx:App]` Wraps the tree in `SWRConfig` (`revalidateOnFocus: false`, `dedupingInterval: 15000`), choosing `MemoryRouter` + `MockLookerExtensionProvider` when `window.__MOCK_LOOKER_EXTENSION__` is defined and `ExtensionProvider` + `LookerExtensionProvider` otherwise.
- `[App.tsx:StudioMain]` Routes in priority order: `PythonTileMount` when `ctl.isTileMount`, `RipperSurfLoader` when `ctl.appInitializing`, `ConfigSetupView` when `ctl.location.pathname === '/config'`, otherwise the `.dab-shell` workspace with `data-theme` and `data-theme-mode`.
- `[PythonTile.tsx:PythonTile]` Guards against concurrent runs with `runningRef.current`, auto-runs bound scripts only when `!isEditing && bindingLoaded && binding?.code` and either `dashboardFilters` JSON changed or `dashboardRunState` transitioned into `'RUNNING'`, and signals `extensionSDK?.rendered?.()` only after view-mode output resolves or when ready without running.
- `[ScriptStudioView.tsx:renderMarkdownOrHtmlString]` Passes full HTML-wrapped strings verbatim and converts all other strings via `renderTddMarkdownToHtml`; `[ScriptStudioView.tsx:ScriptOutputRenderer]` parses JSON arrays of objects into tables (or `'0 rows returned.'`), strings via Markdown/HTML, and other JSON via `<pre>`.
- `[StudioDesignSystem.tsx:StudioModal]` Returns `null` when `!open` and enforces `role="dialog"` + `aria-modal="true"`; `[StudioDesignSystem.tsx:StudioDocPreview]` enforces `pointerEvents: 'none'`, `userSelect: 'none'`, `aria-hidden="true"`, and `tabIndex={-1}`.
- `[StudioSelect.tsx:StudioSelect]` Syncs a hidden native `<select className="dab-studio-select-native">` with the active option and suppresses interaction/Arrow cycling when disabled.
- `[StudioHeader.tsx:StudioBrandAgentName]` Caps agent name input at `maxLength={40}` and resets `draft` on `Escape`; `[StudioHeader.tsx:ConfigSetupView]` renders `Max Tool Rounds` (`config-max-tool-rounds-select`) with an `Escape`-dismissible hover/focus `<Info />` popover (`config-max-tool-rounds-info` / `config-max-tool-rounds-tooltip`, `[data-open="true"]`), disables saving when `busyStatus` is set, `capabilities?.canConfigureExtension === false`, or `authMode === 'apikey' && capabilities?.canManageUserAttributes === false`, and prevents disabling the last enabled mode.
- `[StudioHeader.tsx:StudioTopbar]` Guards folder tree rendering and breadcrumb ancestors with `visited` `Set<string>` cycle checks, disables `folder-popover-open-target-btn` when `selectedFolderId` is empty, and disables `'all'`/`'bq'` health-check scopes when `capabilities?.rolesLoaded && capabilities.sqlRunnerConnections.size === 0`.
- `[StudioWorkspace.tsx:isAllowedExternalWindowUrl]` Permits only `http:`/`https:` URLs on `looker.com`, `looker.app`, `google.com`, `cloud.google.com`, `docs.cloud.google.com`, or `github.com` (and subdomains); `[StudioWorkspace.tsx:isSandboxMarkdownPath]` rejects external schemes and requires a `.md` filename before any `?`/`#`.
- `[StudioWorkspace.tsx:resolveLookerEmbedTarget]` Always returns `{ kind: 'preload', target: '/preload', previewMode: 'preload' }` when `isEmptyConversation`, `isHealthCheckMode`, `isLookmlMode`, or `isTileMode` is true, and otherwise resolves `activeContentItem` > `caConversation` (when `caConversation.embedPath` is non-empty) > `preload` if `builderMode === 'dashboard'` > `publishedApp` > `preload`.
- `[StudioWorkspace.tsx:createLookerEmbedPreloadController]` Serializes `syncTarget` calls via an error-isolated `queue` chain (committing `lastTarget = next` only after load completion), skips redundant updates when `kind`, `target`, and `nonce` match `lastTarget`, and bounces non-preload `nonce`-only updates through `loadUrl({ url: '/preload', pushHistory: false, options: { waitUntilLoaded: true } })` before reloading the target so inline extension bundles and dashboard layouts refresh cleanly.
- `[StudioWorkspace.tsx:StudioComposer]` `@`-mention detection suppresses `/`-skill detection (`detectedSlashSkill.open` is forced `false`), filters `STUDIO_SLASH_SKILLS` across `${sk.id} ${sk.label} ${sk.desc}` while rendering single-line `/<skill-id>` + `{sk.desc}` rows without `{sk.label}` across `composer-slash-skill-menu` (`title="${sk.desc} (${sk.path})"`) and the 3-row `DOC_UI_COMPONENTS.LookmlTurnSkills` preview, excludes hidden explores (`explore.hidden`), deduplicates mentions/chips by `${type}:${id}`, accepts drag-and-drop (`chat-composer-dropzone` `onDragOver`/`onDrop` -> `handleFileInputSelection`) and clipboard paste (`handleImageClipboardPaste`) for images, text/code/`.sql`/`.json`, and PDFs, recalls non-empty `role === 'user'` conversation prompts via unmodified `ArrowUp` (when on line 1 and `historyIdx !== null || !prompt.trim()`, stashing draft, placing caret at end, and suppressing `/` & `@` autocomplete popups) and `ArrowDown` (when `historyIdx !== null` and on the last line, restoring draft past newest and resetting whenever `prompt` diverges or `activeConversationId` changes), disables `studio-send-btn` when `!isAuthenticated` or prompt+images are empty, and routes busy sends to `handleInterjectPrompt` or `handleQueuePrompt`.
- `[StudioWorkspace.tsx:StudioLeftPane]` Clamps long `role === 'user'` messages (`> 5` newline-delimited lines or `> 360` chars) via `.dab-msg-body-collapsed` (`id="user-msg-body-<idx>"` and `data-collapsed="true|false"` emitted only on long user messages, reset on `activeConversationId` change), auto-expanding on clipped `scrollTop > 0` scroll (resetting `scrollTop = 0`) or body click (skipping active long-press, non-empty text selection, and clicks inside `a`, `button`, `:not(pre) > code`, or `[role="menu"]`) alongside `toggle-user-msg-expand-<idx>` (`Show more` / `Show less`, `aria-expanded`, `aria-controls="user-msg-body-<idx>"`), renders image thumbnails (`<img>`) for image attachments and compact file chips (`chat-attached-file-<idx>`) for non-image attachments via `parseAttachmentDataUrl`, renders per-turn inline `crudItems` pills (`chat-object-viewer-chips` / `chat-object-viewer-chip-<key>`, `data-crud-action`) at the bottom of mutating assistant turns (styling `item.action === 'deleted'` with danger/line-through `.deleted`, disabling superseded pills at `.dab-chat-object-chip:disabled:not(.deleted)`, and otherwise unhiding or upserting + focusing `item.key` in `StudioRightPane`), desktop hover/focus-within user message copy buttons (`copy-user-msg-btn-<idx>`, hidden on `(hover: none) and (pointer: coarse)`), and `450ms` mobile touch long-press copy menus (`user-msg-longpress-menu-<idx>` / `user-msg-longpress-copy-<idx>`, cancelled on `> 10px` touch move, dismissing on `Escape` or outside tap while ignoring internal menu touches and suppressing compatibility `touchend` `mousedown` and native `contextmenu`).
- `[StudioWorkspace.tsx:StudioRightPane]` Hides the right pane only when `isEmptyConversation && !activeViewerDocument`, mounts `StudioOverviewSidebar` whenever `!isEmptyConversation` (`isOverviewMode = !isEmptyConversation && !activeViewerDocument && !resolvedStageInspector && !hasActiveViewerPane` as `296px` rail / `<= 768px` mobile bottom sheet, or `docked={!isOverviewMode}` `236px` `.dab-ov-docked` Unified Stage explorer rail / `<= 1080px` slide-over toggled via `stage-explorer-toggle-btn` and hidden via `display: 'none'` when `!isOverviewMode && !isExplorerOpen`, filtering out `'default'` LookML items and `/projects/default` paths via `cleanLookmlProjectId`, always rendering `row.shortTag` instead of `'Hidden'` in Overview `Content`, adding `/dashboards/` and `/looks/` `contentRows` to Overview `Links`, displaying non-image attachment filenames in Overview `Uploads`, and scoping Overview `API Calls` per conversation strictly to Turn Code Mode / CLI Bridge requests where `c.codemode !== false`), requires `activeMode === 'tile' && Boolean(loadedScript || explicitUseCase === 'tile')` for `isTileMode`, opens `content-tab-popover-<key>` immediately (`0ms`) on `onFocus` or when closed while debouncing neighbor tab switches by `180ms` (`hoverOpenTimerRef` cancelled on popover hover and tab leave, `280ms` close grace, `10px` `::before` bridge, `maxLeft` clamped to `window.innerWidth - 328`, resetting `hoveredTab` on tab hide/collapse/conversation switch), spins `<RotateCw />` on `preview-reload-viewer-btn` (`data-reloading`) during manual `Reload Viewer` clicks and warm-turn `embedNonce` `/preload` bounces, renders `<Code2 />` `preview-view-code-btn` + full-height `preview-app-code-drawer` (`isShowingAppCodeFullscreen`, gated on `activePaneKind === 'embed'`, with icon-only `preview-copy-code-btn` via `copyTextWithExtensionSdk` and resetting `showAppCode` on tab/conversation/`embedNonce`/reload), and hides `ca-embed-preview` (`display: 'none'`) when `activePaneKind === 'script' || rightPaneCollapsed || Boolean(activeViewerDocument) || Boolean(resolvedStageInspector) || isShowingAppCodeFullscreen || isOverviewMode` so the Looker iframe stays mounted underneath without reloading.

## Side Effects
- `[App.tsx:App]` Imports `../styles/index.css` at module load and reads `window.__MOCK_LOOKER_EXTENSION__`.
- `[StudioSelect.tsx:__dabSelectPatched]` Patches `window.HTMLSelectElement.prototype.value` descriptor at module load and defines own `value`/`options` properties on the container DOM node.
- `[PythonTile.tsx:PythonTile]` Calls `extensionSDK?.updateTitle?.('')` and `extensionSDK?.rendered?.()`, fetches tile bindings and scripts via `useSWR`, executes Python via `LkrCodeMode.runPythonCode`, and persists bindings via `bindTileScriptArtifact`.
- `[StudioDesignSystem.tsx:StudioModal]`, `[StudioSelect.tsx:StudioSelect]`, `[StudioHeader.tsx:StudioTopbar]`, `[StudioWorkspace.tsx:StudioComposer]`, `[StudioWorkspace.tsx:StudioLeftPane]`, and `[StudioWorkspace.tsx:StudioRightPane]` attach/remove `document` `keydown`/`mousedown`/`touchstart` listeners.
- `[StudioHeader.tsx:FullScreenToggleButton]` Calls `extensionSDK.updateLocation(..., undefined, '_top')` for standalone/spartan fullscreen toggling; `[StudioHeader.tsx:StudioTopbar]` opens `/folders/<selectedFolderId>` via `extensionSDK.openBrowserWindow(..., '_blank')` from `folder-popover-open-target-btn`; `[StudioHeader.tsx:ConfigSetupView]` copies OAuth redirect URIs via `copyTextWithExtensionSdk`.
- `[StudioWorkspace.tsx:StudioComposer]` Runs a 250ms debounced `searchGlobalContentV2` query and mutates `mentionMenuRef.current.scrollTop` when `mockExt.initialExploreScrollTop` is numeric.
- `[StudioWorkspace.tsx:SandboxMarkdownPreviewModal]` & `[StudioWorkspace.tsx:StudioRightPane]` Write `window.__LAST_DOWNLOADED_SANDBOX_MD__`, create/revoke `Blob` URLs to download `.md` files, copy to clipboard, and open Looker paths via `extensionSDK.openBrowserWindow`.
- `[StudioWorkspace.tsx:createLookerEmbedPreloadController]` Initializes `globalThis.window` with a minimal stub when `typeof window === 'undefined'`, initializes Looker Embed SDK, appends/mutates an `<iframe>` in `opts.container`, writes `window.__LOOKER_EMBED_STATE__`, and sends `postMessage` (`looker:ca:layout`) for Conversational Analytics embeds.
- `[StudioWorkspace.tsx:StudioLeftPane]` & `[StudioWorkspace.tsx:StudioRightPane]` Write `window.__LAST_COPIED_THINKING_TRACE__` and copy user messages, thinking traces, TDD Markdown, and `app.js` source via `copyTextWithExtensionSdk`, attach/remove `window` `mousemove`/`mouseup` listeners during split-pane resizing, and query `GET /connections` / `GET /lookml_models` when inspecting `/admin/connections`.
