# skills/data-app-previewer

## Overview
Skill package for starting, managing, and stopping the local Looker Data App preview server and app gallery.

## Subdirectories & Boundaries
- [SKILL.md](./SKILL.md) - Preview server launch, stop, and inspection workflow instructions.
- [tools](./tools/EGM.md) - Python CLI scripts (`start-preview.py`, `stop-preview.py`) for detached preview server startup, HTTP health probing, and workspace-scoped process shutdown.
