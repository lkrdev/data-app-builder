# data-app-previewer skill

A focused skill for AI agents to start, inspect, verify, and manage the local preview server for Looker Data Apps.

See `SKILL.md` for the preview workflow, browser inspection guidelines, and handoffs.

## Layout

```
SKILL.md              Preview server run-order and verification guidelines
tools/
  start-preview.py    Spin up serve.py and open the preview
  stop-preview.py     Shut down the local preview server
```
