# skills

## Overview
Bundled AI skill packages shipped inside the Looker Data Apps distribution payload for authoring, previewing, publishing, upgrading, and updating Data Apps.

## Subdirectories & Boundaries
- [data-app-creator](./data-app-creator/EGM.md) - App authoring workflow, LookML model/explore inspection, palette extraction, tile safety linting, and 4-stage verification tools.
- [data-app-previewer](./data-app-previewer/EGM.md) - Local preview server startup, HTTP health probing, and workspace-scoped shutdown tools.
- [data-app-publisher](./data-app-publisher/EGM.md) - Static widget query extraction and Looker API 4.0 extension dashboard publishing tools.
- [data-app-upgrader](./data-app-upgrader/SKILL.md) - Legacy HTML Canvas Dashboard (`*.canvasdashboard.html`) conversion instructions.
- [toolkit-updater](./toolkit-updater/EGM.md) - Update check, semver comparison, app snapshotting, and locked self-update tools.
